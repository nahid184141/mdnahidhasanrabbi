DARK DEVELOPER PORTFOLIO — QUICK START

1. Open index.html and replace:
   - YOUR NAME (including the navigation brand)
   - Your Name in the project/code/footer text
   - YOUR.EMAIL@example.com with your professional email
   - https://github.com/ with your actual GitHub profile URL

2. Review the CONNECT-ED project description. Keep only claims that accurately describe your contribution and that you have permission to present.

3. Preview by opening index.html in a browser.

4. Publish with GitHub Pages:
   - Create a public repository named exactly YOURUSERNAME.github.io
   - Upload index.html (and this README if you want)
   - Open repository Settings > Pages
   - Under Build and deployment, choose Deploy from a branch
   - Choose branch main and folder /(root), then Save
   - Wait for the site to publish at https://YOURUSERNAME.github.io/

Note: GitHub Pages serves static files only. It does not run PHP or connect to MySQL.
Do not publish database credentials, passwords, private source code or real user data.
